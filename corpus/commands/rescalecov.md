# rescalecov

**rescale the covariance matrix**

Tcl script to rescale the entire covariance matrix used in the proposal 
chain command. 

**Syntax:** `rescalecov`   <scale>

Rescales the chain proposal distribution covariance matrix by the factor
input as `<scale>`.
