# hardcopy

**write plot to file**

Write the current plot to a file.

hardcopy <filename>

This command takes whatever is the current display in your plot window
and writes it to the given filename with a format specified by the
filename suffix. So, e.g. `hardcopy dataplot.ps` will write a
PostScript file
